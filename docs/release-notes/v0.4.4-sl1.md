# v0.4.4-sl1 — 设备兼容与退出恢复

## 中文

### 版本内容

这一版修两个问题：**部分平板无法进入 Steam 界面**，以及**退出游戏后白屏、回不到 SteamOS**。

* **X 服务器改为在会话内部启动。** 有些设备的 Android 在宿主机挂载了全局 `/tmp`（`tmpfs on /tmp`）。
  此前 Xvfb 由 App 在另一个进程里启动，socket 落在根文件系统的 `/tmp`，而会话里的 Steam 和
  `xpresent` 看到的是宿主机的 `/tmp`，两边不是同一个目录，于是连不上 X：表现为黑色或白色画面、
  Steam 界面起不来。现在会话检测不到 X 时会自己启动 Xvfb，保证 X、呈现器和 Steam 在同一命名空间。
* **显式绑定 `根文件系统/tmp → /tmp`**，让两条路径在正常情况下也保持一致。
* **退出游戏后强制重绘。** 游戏运行时窗口管理会把 Steam UI `unmap`；退出后 `map` 回来，但 X 服务器
  不会自动重绘被 unmapped 窗口的内容。部分游戏（如 Hades）因此留下白屏。`xhide map` 现在会在重新
  映射后调用 `XClearArea(..., exposures=True)`，强制完整重绘，Steam 界面立即恢复。
* `xhide` 之前引用的 APK 资源 `libxhide.so` 并不存在，设备上一直是旧版本；本次补上并随包安装。

### 升级方式

覆盖安装即可（`versionCode 17`），运行时、游戏库与配置保留。

### 验证

在受影响设备上：进入 Steam 界面正常；启动并退出 Hades 后自动回到 Steam 界面，不再白屏。

## English

### What changed

Two fixes: **some tablets could not reach the Steam interface**, and **leaving a game left a white
screen instead of returning to SteamOS**.

* **The X server now starts inside the session.** Some devices' Android mounts a global `/tmp`
  (`tmpfs on /tmp`). Xvfb used to be started by the app in another process, so its socket landed in
  the root filesystem's `/tmp`, while Steam and `xpresent` inside the session saw the host's `/tmp`;
  the two paths did not match, the X connection failed, and the result was a black or white screen
  with no Steam UI. The session now starts its own Xvfb when it cannot reach X, so the server, the
  presenter and Steam share one namespace.
* **An explicit `rootfs/tmp → /tmp` bind** keeps both paths identical in the normal case.
* **Repaint after a game exits.** While a game runs, the window manager unmaps the Steam UI; on exit
  it maps it again, but the X server does not repaint an unmapped window by itself. Some games (Hades
  among them) therefore left a white screen. `xhide map` now calls `XClearArea(..., exposures=True)`
  after mapping, forcing a full repaint so the UI comes back immediately.
* The `libxhide.so` asset that `xhide` referenced never existed, so devices kept an old binary; it is
  now shipped and installed with the APK.

### Updating

Install over the previous version (`versionCode 17`); runtime, library and configuration are kept.

### Verified

On the affected device: the Steam interface opens normally, and quitting Hades returns to it without
a white screen.
