# v0.4.0-sl1 — DroidDeck on Redmi K Pad (MT8799)

## 中文

### 版本内容

首个可运行版本：Steam 大屏界面在红米 K Pad 上运行，Windows 游戏可从库中启动并出画面，触控、
键盘与手柄可进入游戏。

应用侧：

* 单 Xwayland 配置（`BL_XWAYLAND_COUNT=1`），游戏与 Steam 客户端共用显示，覆盖层、焦点与
  手柄路由保持一致；
* GPU 状态识别已导入的 PanVK 驱动，不再误报"不受支持"；
* 官方 FPS HUD 改为读取合成器实际上屏帧率，移除重复的帧数显示；
* 设置 → 诊断页新增运行状态（当前运行时驱动、Xwayland 模式）；
* 应用显示名调整为 DroidDeck。

驱动侧：自编 PanVK kbase 驱动（Mesa `5a07217f` + 上游 `csf-v11` 179 个补丁 + 子队列超时保护、
Vulkan 1.4 核心命令别名），以独立包提供，通过"组件 → GPU 驱动 → 导入 .zip"安装。

工具侧：X11 呈现器与窗口工具（`xpresent`、`xraise`、`xhide`、`xwindows`、`xwin`）的源码与
交叉编译脚本已随仓库提供（`tools/xtools/`）。

### 适用设备

红米 K Pad（25079RPDCC），MT8799 / 天玑 9400+，Mali-G925-Immortalis MC12，Android 16。
其他 MTK Mali 设备未经验证。

### 安装

1. 安装 APK 并授予存储权限（与不同签名的版本不能覆盖安装，请先卸载旧版）；
2. **组件 → GPU 驱动 → 导入 .zip**，选择驱动包；
3. 在 `Android/data/dev.hayash1.steamoslite/files/droiddeck-env` 写入：

   ```
   MESA_LOG=android,file
   PANVK_KBASE_GPU_SEMAPHORE_WAITS=0
   BL_NO_GAMESCOPE=1
   BL_STEAM_SOFT_CEF=1
   BL_STEAM_XVFB=1
   ```

4. 启动会话并登录 Steam（首次会下载客户端）。

### 当前局限

* **性能偏低**：Steam 界面约 13–16 fps，游戏在这条显示路径上尚未做性能优化，帧调度与拷贝
  环节仍有优化空间；
* Steam 的 CEF 为软件光栅，是界面帧率偏低的主要原因；
* `p8-common-gates` 在近期构建上出现 SIGSEGV，尚未定位；
* 暂无 bionic 构建，设备侧探针（PanProbe）无法加载该驱动；
* 没有 dmabuf/GBM 导出，显示链路只能拷贝帧；
* G925 / MT8799 组合不在上游验证矩阵内。

### 反馈

问题与建议请提交到 [Issues](../../issues)，附设备信息、`droiddeck-env` 与对应会话日志。

## English

### What is in this release

First runnable build: Steam Big Picture runs on the Redmi K Pad, Windows games launch from the
library and render, and touch, keyboard and gamepad input reaches the game.

Application:

* single-Xwayland configuration (`BL_XWAYLAND_COUNT=1`): games and the Steam client share one
  display, keeping overlay, focus and controller routing consistent;
* GPU status recognises an imported PanVK driver instead of reporting "unsupported";
* the official FPS HUD reads the compositor's presented frame rate; the duplicate counter was removed;
* the diagnostics page shows the active runtime driver and the Xwayland mode;
* the application label is now DroidDeck.

Driver: a self-built PanVK kbase driver (Mesa `5a07217f` + 179 upstream `csf-v11` patches + subqueue
timeout protection and Vulkan 1.4 core command aliases), shipped as a separate package and installed
through **Components → GPU drivers → Import .zip**.

Tools: sources and a cross-build script for the X11 presenter/window tools (`xpresent`, `xraise`,
`xhide`, `xwindows`, `xwin`) are included in `tools/xtools/`.

### Supported device

Redmi K Pad (25079RPDCC), MT8799 / Dimensity 9400+, Mali-G925-Immortalis MC12, Android 16. Other
MediaTek Mali devices are untested.

### Install

1. Install the APK and grant storage access (uninstall any build with a different signature first);
2. **Components → GPU drivers → Import .zip** and select the driver package;
3. Write the session switches into
   `Android/data/dev.hayash1.steamoslite/files/droiddeck-env`:

   ```
   MESA_LOG=android,file
   PANVK_KBASE_GPU_SEMAPHORE_WAITS=0
   BL_NO_GAMESCOPE=1
   BL_STEAM_SOFT_CEF=1
   BL_STEAM_XVFB=1
   ```

4. Start the session and sign in to Steam (the client downloads on first launch).

### Current limitations

* **Performance is low**: the Steam UI runs at roughly 13–16 fps and games are not yet optimised for
  this display path; frame scheduling and the copy path still have headroom;
* Steam's CEF is software-rasterised, the main cause of the low UI frame rate;
* `p8-common-gates` hits SIGSEGV on recent builds; not yet root-caused;
* no bionic build, so the on-device probe (PanProbe) cannot load the driver;
* no dmabuf/GBM export, so the display path copies frames;
* the G925 / MT8799 combination is outside upstream's validation matrix.
