# v0.4.2-sl1 — DroidDeck 自愈更新

## 中文

### 版本内容

这一版把"新设备缺组件"和"新装游戏没映射"两个反复出现的问题收进安装包本身，并且保持**覆盖安装即升级**：同一个包名与签名，`versionCode 15`，数据、运行时和游戏库都保留。

应用侧：

* **运行时文件随 APK 自动安装。** `Xvfb`、`xpresent`、会话脚本
  （`droiddeck-session`、`droiddeck-steamos`、`steam-compatibility`）和 CPU 绑核钩子
  （`libgpuhook.so`）现在打进 APK，启动会话时安装到 Linux 环境；
  `usr/share/X11/xkb` 只在运行时缺少时补齐。新设备不再需要先更新运行时包才能进入 SteamOS。
* **导入的 PanVK 驱动会被自动选中。** 会话启动时如果还没有选择驱动，会自动使用第一个
  PanVK 驱动；否则会退回运行时自带的 freedreno（Turnip）驱动，在 Mali 上找不到设备。
* **导入驱动保留真实库名。** `libvulkan_panfrost.so` 不再被改名，`icd.json` 指向实际文件。
* **旧导入也能识别。** GPU 状态检查同时接受 `libvulkan_panfrost.so` 和标注 PanVK / panfrost 的
  `meta.json`。
* **会话中新装的游戏会自动补兼容映射。** 已安装列表变化后约 10 秒内重跑
  `steam-compatibility`，把新游戏映射到 `droiddeck-proton-arm64`；在此之前，会话中途安装的游戏
  会一直用官方 Proton + SteamLinuxRuntime，在 proot 里启动即退出。
* **CEF 默认绑定到两个最快的大核**（`BL_CPU_MASK=0xc0`），固定滚动负载下 UI 帧率
  12.5–12.8 → 15.4 fps。

### 升级方式

直接覆盖安装即可（`versionCode 15`）。已安装的运行时、游戏库与配置不受影响。

### 适用设备

红米 K Pad（25079RPDCC），MT8799 / 天玑 9400+，Mali-G925-Immortalis MC12，Android 16。
其他 MTK Mali 设备未经本版本验证。

## English

### What changed

This release folds the two recurring fresh-device failures — missing display components and newly
installed games without a compatibility mapping — into the package itself, and stays an in-place
update: same package id and signature, `versionCode 15`; data, runtime and library are preserved.

Application:

* **Runtime files ship inside the APK.** `Xvfb`, `xpresent`, the session scripts
  (`droiddeck-session`, `droiddeck-steamos`, `steam-compatibility`) and the CPU-affinity hook
  (`libgpuhook.so`) are staged into the Linux environment when a session starts;
  `usr/share/X11/xkb` is added only when the runtime lacks it. A fresh device no longer needs a
  runtime-bundle update before SteamOS can start.
* **The imported PanVK driver is selected automatically.** If no driver was chosen, the session uses
  the first PanVK driver; otherwise it falls back to the runtime's bundled freedreno (Turnip)
  driver, which finds no device on Mali.
* **Imported drivers keep their real library name.** `libvulkan_panfrost.so` is no longer renamed and
  `icd.json` points at the file that was written.
* **Older imports are recognised too.** Detection accepts a `libvulkan_panfrost.so` or a `meta.json`
  naming PanVK / panfrost.
* **Games installed during a session get their compatibility mapping.** About ten seconds after the
  installed list changes, `steam-compatibility` runs again and maps the new title to
  `droiddeck-proton-arm64`; before this, a title installed mid-session kept using stock Proton +
  SteamLinuxRuntime, which exits immediately inside proot.
* **CEF is pinned to the two fastest cores by default** (`BL_CPU_MASK=0xc0`): 12.5–12.8 → 15.4 fps
  under a fixed scroll workload.

### Updating

Install over the previous version (`versionCode 15`). The installed runtime, library and
configuration are kept.

### Supported device

Redmi K Pad (25079RPDCC), MT8799 / Dimensity 9400+, Mali-G925-Immortalis MC12, Android 16.
Other MTK Mali devices are not validated by this release.
