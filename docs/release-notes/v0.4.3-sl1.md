# v0.4.3-sl1 — Proton 故障可诊断

## 中文

### 版本内容

这一版只做一件事：**让 Proton 的失败可被诊断**。它修复的是"游戏启动即退，但没有任何日志"的问题。

* `droiddeck-proton-run` 现在把 Proton 的 stderr 写入 `/tmp/droiddeck-proton-<AppID>.log`；
* 该脚本随 APK 自动安装（`SessionFiles`），覆盖安装即可生效，不需要更新运行时包。

背景：《Left 4 Dead 2》（AppID 550）在强制走 `droiddeck-proton-arm64` 后仍然启动即退。
它之前走的是原生 Linux 版 + FEX + SteamLinuxRuntime，同样几秒退出。由于 Proton 的输出没有被保存，
无法判断是"缺少 32 位支持"还是别的错误。完整分析见
[docs/PROTON-32BIT.md](PROTON-32BIT.md)。

### 已知限制

* L4D2 尚未验证可玩；本版本只补上日志，便于定位（32 位游戏需要额外验证 i386 支持）；
* 丝之歌能进入游戏，但游戏内输入仍未解决（Steam Input 布局与虚拟手柄的配合问题，仍在排查）。

### 升级方式

覆盖安装即可（`versionCode 16`），运行时与游戏库保留。

## English

### What changed

One fix: **Proton failures are now diagnosable**. It addresses "the game exits at launch and there is
no log at all".

* `droiddeck-proton-run` writes Proton's stderr to `/tmp/droiddeck-proton-<AppID>.log`;
* the script ships inside the APK and is staged at session start, so an in-place update is enough.

Background: *Left 4 Dead 2* (AppID 550) still exits immediately when forced onto
`droiddeck-proton-arm64`; before that it used the native Linux build through FEX and the Steam Linux
Runtime and also exited within seconds. Proton output was discarded, so the failure could not be
classified. See [docs/PROTON-32BIT.md](PROTON-32BIT.md) for the full analysis.

### Known limitations

* L4D2 is not playable yet; this release only adds the log needed to identify the cause (32-bit games
  need i386 support verified);
* Silksong reaches the main menu but in-game input is still unresolved (Steam Input layout vs. the
  virtual controller, under investigation).

### Updating

Install over the previous version (`versionCode 16`); runtime and library are preserved.
