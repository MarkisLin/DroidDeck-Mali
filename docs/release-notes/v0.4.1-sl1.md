# v0.4.1-sl1 — DroidDeck 显示管线健壮性与性能更新

## 中文

### 版本内容

这次更新解决了两类问题：一台全新设备上"进不去 SteamOS / GPU 显示不支持"，以及 Steam UI 帧率偏低。

应用侧：

* **导入的 PanVK 驱动保留真实库名。** 之前导入时会把 `libvulkan_panfrost.so` 改名成
  `libvulkan_freedreno.so`，导致运行时和界面互相矛盾；现在写入的就是实际文件名，`icd.json` 指向它。
* **旧导入也能被识别。** GPU 状态检查同时接受 `libvulkan_panfrost.so` 和 `meta.json` 中标注
  PanVK / panfrost 的驱动目录，已经用旧版本导入过的设备不会再显示"不支持"。
* **CEF 默认绑定到两个最快的大核**（`BL_CPU_MASK=0xc0`）。Steam 启动 helper 时用 `taskset 0x7c`，
  把两个小核混进来、又漏掉最快的大核；会话在 exec 阶段改写该掩码。固定滚动负载下实测：
  **12.5–12.8 fps → 15.4 fps（+15–20%）**，分辨率与画质不变。可用 `BL_CPU_MASK` 覆盖。

运行时侧：

* 显示栈需要 `Xvfb` 和本项目的 `xpresent` 呈现器。早于本版本的运行时包如果缺少它们，
  Steam 会报 `Unable to open X11 display`，会话也不会输出任何一帧。

### 适用设备

红米 K Pad（25079RPDCC），MT8799 / 天玑 9400+，Mali-G925-Immortalis MC12，Android 16。
其他 MTK Mali 设备未经本版本验证。

### 安装与升级

1. 安装 APK（与旧版本签名一致可直接覆盖）；
2. **组件 → GPU 驱动 → 导入 .zip**，选择驱动包（旧版本导入过的可跳过）；
3. 在 `Android/data/dev.hayash1.steamoslite/files/droiddeck-env` 写入：

   ```
   MESA_LOG=android,file
   PANVK_KBASE_GPU_SEMAPHORE_WAITS=0
   BL_NO_GAMESCOPE=1
   BL_STEAM_SOFT_CEF=1
   BL_STEAM_XVFB=1
   BL_XWAYLAND_COUNT=1
   ```

4. 确认来宾系统里有 `Xvfb` 和 `xpresent`（`ls /usr/bin/Xvfb /root/xpresent`）；
5. 启动 Steam；如需调整 CPU 绑核，加 `BL_CPU_MASK=0xf0`（四个大核）或 `0xff`（全部核心）。

## English

### What changed

This release fixes the experience on a fresh device (no way into SteamOS, GPU reported as
unsupported) and lifts the Steam UI frame rate.

Application:

* **Imported PanVK drivers keep their real library name.** The installer used to rename
  `libvulkan_panfrost.so` to `libvulkan_freedreno.so`; `icd.json` now points at the file that was
  actually written, so the runtime and the UI agree on what was imported.
* **Drivers imported before this fix are recognised too.** Detection accepts a
  `libvulkan_panfrost.so` or a `meta.json` naming PanVK / panfrost, so older imports no longer show
  "unsupported".
* **CEF is pinned to the two fastest cores by default** (`BL_CPU_MASK=0xc0`). Steam launches its
  helper with `taskset 0x7c`, which mixes little cores in and leaves the fastest core out; the
  session rewrites that mask at exec time. With a fixed scroll workload: **12.5–12.8 fps →
  15.4 fps (+15–20%)**, no change to resolution or image quality. `BL_CPU_MASK` overrides it.

Runtime:

* the display stack needs `Xvfb` and this project's `xpresent` presenter. Runtime bundles older than
  this release that miss them make Steam fail with `Unable to open X11 display` and present no
  frames at all.

### Supported device

Redmi K Pad (25079RPDCC), MT8799 / Dimensity 9400+, Mali-G925-Immortalis MC12, Android 16.
Other MTK Mali devices are not validated by this release.
